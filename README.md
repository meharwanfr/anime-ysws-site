# Anime YSWS 
ship anime projects, get cool anime prizes


This is a reactjs website for the anime YSWS (my draft YSWS Program for 2nd round submission of gap year interview at Hack Club)

[Live Link Here](https://anime-ysws-site.vercel.app/)


- YSWS -> You Ship We Ship (basically a program where You Ship a coding/hardware/art project and We Ship you a prize for your hardwork)

## Project setup

after cloning the repo, run :
```
cd anime-ysws-site
npm install
```

then just run the react app using this command :
```
npm run dev
```
